# 全屏背景

后台 → 设置 → 网站设置 → 全屏背景。选择来源后保存设置；上传图片直接保存。

- 上传图片：存入当前媒体存储，通过站内媒体地址显示。
- 在线图片：填写公开 HTTPS 图片地址。
- 图片 API：支持直接返回图片或跳转到图片；选择 JSON 时填写地址字段，例如 `url`、`data.url`、`images.0.url`。空字段默认 `url`，相对地址按 API 地址解析。JSON API 须允许跨域访问，浏览器请求不携带登录凭据。使用公开无密钥的接口，URL 与返回图片会被访客浏览器读取。
- Bing 每日一图：站内固定接口读取 Bing 当日图片，依次使用 Bing、Bing 中国和 bing.biturl.top 的固定公开端点，缓存一小时；使用原图地址，版权信息在接口 JSON 中保留。失败时保持纯色背景。

不透明度为 0–100%，滑动立即预览，点击保存设置持久保存。切换来源保留已上传背景，切回上传可继续使用；移除背景解除当前配置，原文件保留在文件库。背景 API 页面首次加载时获取，背景固定铺满整个视口；图片缓存遵循资源服务器的响应头，不定时轮询。JSON 请求超时 10 秒、数据上限 64 KiB；图片不可访问、字段不存在或跨域被拒绝时，设置页面显示错误。
