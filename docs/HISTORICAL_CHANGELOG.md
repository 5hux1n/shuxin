# 旧发布记录

以下为重新建立初始发布前的已公开版本记录，对应原 Git 标签保留。

## 1.0.25 — 2026-10-12

- 设置新增独立存储菜单，网站、用户、系统设置统一分区与对齐，切换页面保持稳定。
- 编辑器改用紧凑 Lucide 图标工具栏；图片与 Live Photo 合并并自动配对，音频、音乐分享和歌单统一识别导入。
- 全屏背景新增 HTTPS 图片、图片/JSON API 和 Bing 每日一图来源，保留上传与不透明度调整。
- 修正网盘链接编辑表单的输入框样式。

## 1.0.24

- 系统设置新增可选第三方文件存储，支持阿里云 OSS、腾讯云 COS、七牛云 Kodo、Cloudflare R2 与 S3 兼容服务。
- 存储配置支持连接检查、凭据加密保存和切换；旧文件保留原位置，媒体访问权限与完整备份保持一致。

## 1.0.23 — 2026-10-11

- 演示博客主域名启用 shuxin.my，移除旧域名绑定；仓库 Demo 入口与部署说明同步更新。

## 1.0.22 — 2026-10-11

- 图片 Logo 与文字 Logo 可独立设置，同时设置则并排显示，至少保留一项；移除模式切换与输入框占位文字。
- 网站标题与副标题为可选，浏览器标题拼接网站标题、副标题和文字 Logo，忽略空值及重复内容；全部留空时使用站长昵称与简介。

## 1.0.21 — 2026-10-11

- 网站 Logo 支持文字与图片切换，文字 Logo 使用本地 Space Grotesk 字体，切换和修改自动保存；网站名称改为可选，留空时使用 Logo 文字或 ShuXin。

## 1.0.20 — 2026-10-11

- 新增 Cloudflare 一键部署入口与独立的公共部署配置，部署到自己的账号和域名。
- 提供预构建服务器运行包、自动生成配置的安装工具和宝塔启动入口，无需服务器端构建前端。

## 1.0.19 — 2026-10-11

- 百度、阿里、夸克、123 云盘下载卡片改用 App Store 高清应用图标。

## 1.0.18 — 2026-10-11

- 文件与网盘下载卡片采用更短的宽度，桌面最大 400px，手机随容器缩放。

## 1.0.17 — 2026-10-11

- 新增文件附件上传、编辑与下载卡片，支持分块传输、草稿和可见性权限，文件随动态删除及数据导出。
- 新增网盘与 HTTPS 下载链接卡片，支持资源名称和提取码；百度、阿里、夸克、123 云盘使用本地图标，未知来源使用默认图标。
- 文件类型显示对应图标，卡片右侧统一使用下载 SVG 按钮。

## 1.0.16 — 2026-10-11

- 歌单下一首按钮改用 fast-forward SVG 图标。

## 1.0.15 — 2026-10-11

- 歌单切歌与播放模式改用指定的 Lucide SVG 图标，新增静音/取消静音按钮，切换曲目时保留静音状态。
- 歌单行缩小封面与上下留白，采用更紧凑的单行展示。

## 1.0.14 — 2026-10-11

- 歌单卡片增加统一的小尺寸图标式上一首、下一首、列表展开及播放模式控制，曲目列表默认收起。
- 播放模式可切换单曲循环、随机播放、顺序播放；顺序播放结束后停止。
- 展开的歌单使用圆角面板和分层排版，按序号、封面、同一行曲名与作者展示，长文字支持横向滑动，隐藏音频格式后缀；每首可直接播放或暂停，并同步当前曲目状态。

## 1.0.13 — 2026-10-11

- 后台动态列表按预览标题、简短摘要和操作区分层显示，图片增加缩略图，音频、视频、Live Photo、歌单和代码显示内容标识。
- 摘要省略代码正文与音乐播放器内部文字，日期补充时分，便于浏览和编辑记录。

## 1.0.12 — 2026-10-11

- 移除酷狗、酷我分享链接解析与平台歌单导入，只保留网易云、QQ、汽水；历史正文中的相关链接按普通超链接显示。
- 更新编辑器提示、功能说明与线上音乐展示，移除不可用平台的示例卡片。

## 1.0.11 — 2026-10-11

- 网易云优先使用平台公开音源，支持站内卡片播放和歌单连播；无音源时保留官方播放器。
- 修正 QQ 音源请求的文件名、媒体 ID 与平台返回的 CDN 地址处理，明确提示未提供公开音源的歌曲。
- 音乐音源缓存限制为两分钟；加载失败后再次点击重新解析，减少过期链接持续无法播放的问题。

## 1.0.10 — 2026-10-11

- 音乐分享解析扩展酷我及 QQ、汽水、酷狗短链接；展示歌曲资料、封面和平台公开音源状态。
- 发布器支持导入公开平台歌单、M3U / JSON 文件及多行歌曲链接，提供曲目切换、列表循环、单曲循环与顺序播放。
- 上传 WMA 时在浏览器内转换为 MP3；音频直链扩展 WMA 与 MKA 识别，实际播放取决于浏览器编解码能力。
- Markdown 代码块增加语法高亮、行号、换行开关和复制功能。
- 编辑器内置猫猫、兔兔、日常三组原创表情包。

## 1.0.9 — 2026-10-10

- 媒体展示移除下载与外部平台入口；音频文件、音频直链与音乐分享统一为封面、标题、歌手/来源与播放按钮的横向卡片，缺失封面时显示生成的默认封面。
- 图片支持配置点击跳转网址，发布器新增 Markdown 工具栏并补齐音频链接按钮样式。
- 网站支持上传全屏背景并调整不透明度；Logo 与头像上传、移除操作直接保存。
- 后台统一“设置”入口，提供网站、用户、系统子菜单；用户资料与登录名、密码、登录状态、数据导出分别管理。
- 可见性文字移除特殊字符，页脚品牌统一为 ShuXin。

## 1.0.8 — 2026-10-10
