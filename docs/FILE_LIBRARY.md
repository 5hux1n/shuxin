# 文件管理与复用

后台 `/admin/files` 管理由本站上传、数据库记录的本地、Workers 内置和 OSS 文件，不扫描存储桶中其他文件。

点击文件管理页面的“上传文件”可先把文件入库，无需写动态。支持多选，自动区分图片、视频、音频和附件，使用当前配置存储；上传完成后刷新列表。上传失败时保留已完成项，其余文件不自动重试。

按图片、视频、音频、附件分类，可单个或批量删除。每页 60 项，全选只选择当前已加载分类中的可删除文件。Live Photo 封面与片段按一组管理。正在使用的头像、Logo、背景需先在设置中更换。

在编辑器下方点“文件库”，选择已有资源并点“插入”，即可在光标处插入 Markdown：

```md
![图片描述](/media/原图片ID)

[音频名称](/media/原音频ID)

[视频名称](/media/原视频ID)

[附件名称](/media/原附件ID)
```

直接使用原文件，不复制、不重新上传，也不创建新文件记录。图片在正文显示；独立段落中的音视频链接渲染播放器，附件链接可下载。Live Photo 会插入封面及原片段链接。文件库显示被正文引用的动态数量。

删除动态、从动态移除附件、替换头像/Logo/背景只解除对应使用关系，原文件保留在文件库；需要彻底删除文件时到文件管理操作。文件库删除会使所有引用该文件的内容失效，操作前有明确确认。已删除文件的 Markdown 链接需移除后才能保存动态。

读取需要站长登录，删除需要同源与 CSRF。站长始终可访问文件；匿名访问只允许当前公开外观、可读取动态的附件，或已发布且非私密动态实际 Markdown 引用的文件。草稿和私密引用不会开放匿名访问。同一文件只要被站长用于公开/不列出且已发布的动态，它的原地址就可访问；仅剩草稿/私密使用关系时恢复为站长可读。Live Photo 片段继承封面引用的访问权限。

OSS 删除失败保留记录并提示失败数量；超时后请刷新确认状态再决定是否重试。本轮未执行构建、测试或浏览器验收。
