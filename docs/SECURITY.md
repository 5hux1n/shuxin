# 安全设计说明

这是安全设计说明。实际执行的审核、验收及其边界见根目录 AUDIT_REPORT.md。

## 身份与写入

- `owner.id=1` 由数据库 CHECK 限定；首次初始化直接填写登录名、昵称和密码，检查现有账号并在写事务中创建，不能覆盖账号；保留同源校验、CSRF 和限流。
- 新密码使用 PBKDF2-SHA256（随机 16 字节盐、600000 次迭代、32 字节输出），Node 使用 WebCrypto，Workers 使用 @noble/hashes 的标准 PBKDF2 实现以避开平台 WebCrypto 迭代上限，输出格式相同；Node 保留读取本地早期 scrypt 哈希的能力，允许任意非空密码，不设最低字符数。密码比较使用 timingSafeEqual；数据库不存密码原文。
- 会话由 32 字节随机 token 构成，数据库仅存 SHA-256 摘要，14 天绝对过期。Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下 Secure；退出删除会话；改密码使全部会话失效。
- 登录、初始化和密码修改有数据库持久化限流。单站点全局登录限制为每 15 分钟 40 次，登录名限制为 8 次；反向代理仍应限制外部洪泛请求。
- 管理页面由服务端 middleware 鉴权。所有写接口在 HTTP 层调用 guard，校验站长认证（初始化/登录例外）、SITE_URL Origin 和随机双提交 CSRF token。Cookie 中的 CSRF token 为 HttpOnly，仅通过当前页面 meta 提供给同源脚本。
- JSON 流读取限制为 256KB，所有业务输入使用 Zod 校验。动态更新带 updatedAt 防止旧编辑页面无提示覆盖新修改。

## 内容和公开输出

- 原文存 Markdown，统一经 marked 与 sanitize-html 渲染；HTML 仅保留基本排版白名单，不执行脚本、事件属性、样式、iframe 或危险协议。禁用外部正文图片标签；本站资源图片只接受 UUID 媒体路径，读取仍由媒体路由鉴权。
- public/published 才能进入时间线、搜索 与 sitemap。unlisted/published 只可通过直达链接读取，不是秘密链接保护；详情 noindex，OG 不输出正文或图片。
- draft/private 只有站长认证后可读；不存在和不可访问的详情都返回 404。受限详情不把正文/图片写入 OG。
- 媒体不是 public 静态文件。每次 `/media/:id` 读取依据站长身份、头像或所属动态状态/可见性判定；未关联的上传只对站长可见。头像是显式公开内容。
- 响应默认 no-store 并 Vary Cookie，防止已登录内容进入共享缓存；媒体也 private/no-store。不要在反向代理上覆盖此策略。

## 图片与存储

- 流式限制单图 10MB，sharp 按真实解码类型检查 JPG/PNG/WebP/GIF，最大边 10000px，最多 3200 万像素；服务重新编码静态 WebP、自动旋转并去除源元数据。GIF 不保留动画。动态最多 12 图。
- 文件名由服务器 UUID 生成，存储 key 严格限定 UUID.webp；用户输入不参与路径选择。上传字节不直接作为可执行网页返回，响应固定 MIME 和 nosniff。
- 删除动态/移除媒体只解除附件归属，文件保留在文件库，彻底删除需在文件管理操作。未保存的上传留在数据库，只有站长可读；可以通过导出保有，或在后台文件管理中删除未关联记录。未加入自动定时清理，避免误删长时间编辑中的图片。
- 数据目录和备份不应对外公开。Workers 使用 Durable Object SQLite 和分块图片事务持久化；Node 使用 SQLite 和本地文件。SQLite 参数化查询，Schema migration 在事务内应用，不清空数据库。

## 浏览器与部署

默认发送 nosniff、DENY framing、Referrer-Policy 和 CSP。CSP 允许同源脚本，初始化主题内联脚本须匹配每次请求的随机 nonce；样式允许内联，Markdown 净化负责正文白名单；API 请求限定同源，外部媒体和封面按固定平台 CDN 规则使用，不加载远程脚本。生产使用 HTTPS、随机秘密与非 root 容器。应用没有公开注册、API token、OAuth 或旧系统兼容入口。

导出包含敏感数据及密码哈希，主动清除活动会话；导出适合小站，ZIP 使用内存缓冲。部署者负责系统补丁、TLS、反向代理限流、资源配额和异地备份。发生异常不向客户端返回堆栈或密钥。

## 音视频与音乐分享

- 音视频每个分块及完成/取消操作均要求站长会话、同源请求和 CSRF。完成前没有可访问的媒体记录；真实文件头及容器轨道通过后才关联动态。分块必须按准确偏移和长度上传，默认文件上限 512 MB。
- 音视频遵循与图片相同的草稿/私密/不列出规则，Range 响应同样先鉴权；流式输出避免完整媒体占用内存。
- 音乐解析只读取固定 HTTPS 平台主机，不带用户凭据，禁止跨平台重定向，最多 6 次请求、12 秒跳转读取、2 MB 文本。仅接受平台 CDN 提供的公开音频链接；没有公开来源时只展示资料卡片与原因。
- 外链播放器默认不加载；正文中的任意 iframe、自动播放、事件属性仍被净化，网易云 iframe 只由点击后的客户端代码创建。

## 设置与图片链接

背景与 Logo、头像都是经过解码校验的站内图片；三种配置互斥，不能占用已关联动态或 Live Photo 的图片，动态保存也不能引用这些配置图片。背景作为公开站点外观可供访客读取。更换外观只解除旧使用关系，文件留在文件库。图片跳转只接受不含凭据的 HTTP/HTTPS 地址，外部链接带 noopener/noreferrer。资料与网站设置的部分更新仅修改实际提交的字段，上传自动保存不提交未确认的文字或登录名。歌曲封面仅接受固定平台图片 CDN 的 HTTPS 地址，失败使用站内占位符，不扩展 Markdown 任意图片或 iframe 的权限。任务列表输入仅渲染禁用的只读复选框。

歌单导入需要站长会话、CSRF 与限流；导入曲目只接受受支持的 HTTPS 音频/音乐网址及本站 UUID 媒体路径，媒体访问权限保持不变。歌单不会自动下载曲目；点击播放才请求音源。表情图片仅允许内置清单，任意 Markdown 图片仍不渲染。代码高亮结果继续经过统一净化。WMA 转换在独立 Web Worker 本地运行，单线程 WASM 不要求跨站隔离；组件只在选择 WMA 时加载，服务器仍校验转换后的媒体。来源策略使用 no-referrer，不向音源服务器发送本站来源。

文件库仅站长可访问，删除与复用要求同源及 CSRF；复用直接插入同一文件的 Markdown 链接，不生成副本；访问权限依据原附件归属或可读取的已发布正文引用判断。删除已关联媒体会使原动态失去对应附件；正在使用的头像、Logo 与背景受删除保护。见 [FILE_LIBRARY.md](FILE_LIBRARY.md)。
