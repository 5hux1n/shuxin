The reproducible asset packaging script is scripts/prepare-audio-codec.mjs.
It copies the upstream JavaScript without changes and splits the upstream
WASM into chunks only to comply with hosting asset size limits; the browser
reassembles the exact original bytes. No user file is sent to another service.
